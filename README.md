# Lesson 2: AI History

A GitHub Pages-ready static website lesson for high school CTE Artificial Intelligence and Machine Learning students.

## Lesson Focus

This lesson focuses only on **AI History**. Neural networks, deep learning, transformers, and modern generative AI appear as historical milestones only. They are intentionally previewed for deeper study in Lesson 3.

## How to Use Locally

Open `index.html` in a browser. No build tools or paid frameworks are required.

## How to Edit the Lesson

Most lesson content is in:

```text
js/lesson-data.js
```

Edit this file to update:
- lesson title and subtitle
- learning goals
- vocabulary
- timeline milestones
- industry examples
- video/reading worksheet questions
- activity directions
- quiz questions
- exit ticket
- teacher notes

## How to Replace the AI History Map Image

Replace this file:

```text
assets/images/ai-history-map.png
```

Keep the same file name if you do not want to edit the code.

## Hosting on GitHub Pages

1. Create a new GitHub repository.
2. Upload all files and folders from this project.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/root`.
6. Save.
7. GitHub will provide a public URL for the lesson.

## Classroom Notes

Suggested flow for 2.5 hours:

1. Bell ringer: 8 minutes
2. Vocabulary preview: 10 minutes
3. AI History Map activity: 15 minutes
4. Timeline direct instruction: 45–55 minutes
5. Video/reading worksheet: 15–20 minutes
6. AI History Exhibit project: 35–45 minutes
7. Gallery walk: 10–15 minutes
8. Quiz and exit ticket: 10–15 minutes
